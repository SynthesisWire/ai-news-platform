# ADR-0004 — Notion Is an Editorial Adapter, Not the Public Database

**Status:** Accepted

## Decision

Keep the existing AI Research Hub as an editorial/research surface during migration. Synchronize approved/candidate data into the platform through a Notion adapter.

The public website never reads Notion on request paths.

## Rationale

This preserves the existing workflow while gaining transactional publishing, version history, reliable search, localization, APIs, corrections, and scalable delivery.
