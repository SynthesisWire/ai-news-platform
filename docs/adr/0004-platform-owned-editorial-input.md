# ADR-0004 — Platform-owned editorial input

Status: superseded and replaced on 2026-11-02.

The previously proposed Notion integration was abandoned. It is not a supported input, adapter, synchronization path or future project dependency. This single historical record explains the decision change; no external pages or automations were changed.

The platform owns editorial input and publication review. The current local increment uses administrative CLI commands under OS/database access, with human-authored bilingual text and explicit review. Any future hosted editorial interface requires its own approved identity/authorization design.
